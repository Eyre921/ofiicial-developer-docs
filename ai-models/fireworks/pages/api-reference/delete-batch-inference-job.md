---
title: "Delete Batch Inference Job"
source: https://docs.fireworks.ai/api-reference/delete-batch-inference-job
path: api-reference/delete-batch-inference-job
---

delete /v1/accounts/{account_id}/batchInferenceJobs/{batch_inference_job_id}
Delete a batch inference job from your Fireworks account by sending a DELETE request with the account ID and batch inference job ID path parameters.
