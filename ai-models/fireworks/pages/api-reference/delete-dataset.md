delete /v1/accounts/{account_id}/datasets/{dataset_id}
Delete an existing dataset from your Fireworks account by sending a DELETE request with the account ID and dataset ID path parameters.

> [!NOTE]
>
> Dataset creation, uploads, updates, validation, and downloads are retired on Fireworks. Use `DeleteDataset` to permanently remove existing dataset records from your account.
