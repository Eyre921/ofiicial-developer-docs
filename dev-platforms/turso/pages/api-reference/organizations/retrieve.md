GET /v1/organizations/{organizationSlug}
Retrieve details of a specific organization.

<RequestExample>
  ```bash theme={null}
  curl -L https://api.turso.tech/v1/organizations/{organizationSlug} \
    -H 'Authorization: Bearer TOKEN'
  ```
</RequestExample>
