## Available tools

| Action | What it does | Tool name |
| - | - | - |
| Find your calendars | See calendars grouped by connected account. | [`notion-calendar-list-calendars`](/guides/mcp/tools-calendars-reference#list-calendars) |
| See upcoming events | Read events across connected calendars for a chosen period. | [`notion-calendar-list-events`](/guides/mcp/tools-calendars-reference#list-calendar-events) |
| Check coworkers’ schedules | Read coworkers’ events within your organization. | [`notion-calendar-list-coworkers-events`](/guides/mcp/tools-calendars-reference#list-coworkers-events) |
| Find a meeting room | Find rooms and other calendar resources for a chosen time. | [`notion-calendar-list-calendar-resources`](/guides/mcp/tools-calendars-reference#find-calendar-resources) |
| Find people to invite | Find contacts by name or email. | [`notion-calendar-list-contacts`](/guides/mcp/tools-calendars-reference#find-contacts) |
| Schedule an event | Create events on calendars you can edit. | [`notion-calendar-create-events`](/guides/mcp/tools-calendars-reference#create-calendar-events) |
| Change meeting plans | Update an existing event. | [`notion-calendar-update-events`](/guides/mcp/tools-calendars-reference#update-calendar-events) |
| Cancel an event | Cancel a calendar event. | [`notion-calendar-cancel-events`](/guides/mcp/tools-calendars-reference#cancel-calendar-events) |

## Things to know

These tools use your connected Calendar accounts. Creating an event may notify attendees. Finding rooms requires a Google Workspace account with permission to view calendar resources.
