## Available tools

| Action | What it does | Tool name |
| - | - | - |
| Create pages | Draft documents and apply database templates. | [`notion-create-pages`](/guides/mcp/tools-pages-reference#create-pages) |
| Edit a page | Update a page’s content and properties. | [`notion-update-page`](/guides/mcp/tools-pages-reference#update-a-page) |
| Move pages | Put pages in a different location. | [`notion-move-pages`](/guides/mcp/tools-pages-reference#move-pages) |
| Copy a page | Duplicate an existing page. | [`notion-duplicate-page`](/guides/mcp/tools-pages-reference#duplicate-a-page) |
| Move pages to Trash | Remove pages you no longer need. | [`notion-delete-pages`](/guides/mcp/tools-pages-reference#delete-pages) |
| Check progress | Check whether a page creation or update has finished. | [`notion-get-async-task`](/guides/mcp/tools-pages-reference#get-async-task-status) |

## Things to know

Tell your assistant where to save new pages. If you do not specify a destination, it creates a private page. To review changes, suggest edits, or recover deleted pages, see [Work together in Notion](/guides/mcp/tools-comments).
