openapi-adminApi.json GET /v1/analytics/reports
List analytics reports.

The organization bot token must have every scope in one of the following sets:

* Option 1:
  * `analytics:ai-analytics`
* Option 2:
  * `analytics:user-activity`
* Option 3:
  * `analytics:page-content`
