title: "Unmute a user in a broadcast chat"
source: https://docs.x.com/x-api/broadcasts/unmute-a-user-in-a-broadcast-chat
path: x-api/broadcasts/unmute-a-user-in-a-broadcast-chat
---

delete /2/broadcasts/{id}/chat/mutes/{user_id}
Allows a muted user to post messages in a running broadcast chat again. The authenticated user must own the broadcast.
