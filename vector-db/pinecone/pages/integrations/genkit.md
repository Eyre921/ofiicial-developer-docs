Use the Genkit Pinecone plugin with Firebase to build AI features with type-safe indexers, embedders, and retrievers for RAG and semantic search apps.

[Genkit](https://firebase.google.com/docs/genkit) is a framework from Firebase for building AI features into your apps. The Genkit Pinecone plugin provides indexer, embedder, and retriever abstractions that reduce the work of integrating AI components. With the plugin, you can combine AI models with your own custom logic and data to build AI features for your business.

You can also analyze unstructured text, generate creative content, select tasks, and send results back to your app as structured, type-safe objects. The plugin provides a common format for content that supports combinations of text, data, and other media. You can use Genkit for models that perform any generative task, such as image generation, not just LLMs.
