Learn how to build a Pinecone integration with the public SDKs and API, and how to apply to have it listed on the Pinecone integrations page.

Anyone can use the [Pinecone SDKs](/reference/pinecone-sdks) or the [Pinecone API](/reference/api/introduction) to build a native Pinecone integration. You're free to build and launch an integration to support your users.

Listings on the [Integrations overview](/integrations/overview) are curated. We prioritize applications from integrations that are actively used by mutual customers. If you think your integration qualifies for official partner support, fill out the [application form](https://dash.partnerstack.com/application?company=pinecone\&group=technologypartners).
