Use the Estuary Pinecone connector to build real-time, millisecond-latency pipelines that incrementally embed source data for LLM search and RAG.

[Estuary](https://estuary.dev/) builds real-time data pipelines that focus on moving data from sources to destinations with millisecond latency. It supports integrations with hundreds of systems including databases, warehouses, SaaS products, and streaming solutions.

The Pinecone connector for Estuary moves data from these systems to Pinecone and keeps it up to date. It updates source data incrementally, which minimizes the credits you use to get embeddings from providers before pushing them to Pinecone.

You can use Estuary's Pinecone connector for use cases like LLM-based search across your organization's data and recommendation systems. You can set it up in 5 minutes without engineering effort.
