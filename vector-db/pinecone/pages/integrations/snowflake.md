Deploy Pinecone on Snowpark Container Services to run vector search and GenAI apps inside Snowflake without moving data out of your warehouse.

Snowpark Container Services is a fully managed container offering for deploying, managing, and scaling containerized applications in Snowflake. You can deploy and run Pinecone with Snowpark Container Services, so your data doesn't need to leave the Snowflake environment for processing.

Unlike traditional container orchestration platforms like Docker or Kubernetes, Snowpark Container Services provides an OCI runtime execution environment optimized for Snowflake, which runs OCI images on Snowflake's data platform.
