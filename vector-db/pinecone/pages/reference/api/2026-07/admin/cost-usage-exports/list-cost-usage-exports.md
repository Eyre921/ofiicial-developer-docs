https://raw.githubusercontent.com/pinecone-io/pinecone-api/refs/heads/main/2026-07/admin_2026-07.oas.yaml get /admin/cost-usage-exports
List the cost usage exports belonging to your organization, newest first.

List items never carry a download link: `download_url` and `download_url_expires_at` are always `null` here. Request a single export to generate one.
