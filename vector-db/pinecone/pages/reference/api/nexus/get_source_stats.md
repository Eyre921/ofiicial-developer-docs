https://raw.githubusercontent.com/pinecone-io/pinecone-api/refs/heads/main/2026-07/nexus_2026-07.oas.yaml GET /contexts/{slug}/source/stats
Aggregate counts. Under preview mode the response also carries the per-context quota (`max_files_per_context`, `max_bytes_per_context`, `used_files`, `used_bytes`); those fields are absent otherwise.
