Run sparse-vector search in Pinecone over a document index, querying with text or with a sparse vector you generate.

This page shows you how to search an [index with sparse vectors](/guides/indexes/index-data-overview#sparse-vector-search) for documents that most exactly match the words or phrases in a query.

> [!NOTE]
>
> For general-purpose text retrieval (product search, content discovery, document Q\&A), we recommend [full-text search](/guides/search/full-text-search). Full-text search runs over `string` fields you've declared with `full_text_search` enabled, using BM25 ranking and Lucene query syntax. The multi-field schema also lets you add `dense_vector` or `sparse_vector` ranking later in the same index.
>
> Sparse-vector search (this page) is a distinct retrieval mode. Reach for it when you want token-weighted retrieval with sparse vectors, either generated by Pinecone from a `sparse_embed` field ([`pinecone-sparse-english-v0`](/models/pinecone-sparse-english-v0) by default) or produced by your own sparse encoder.

Sparse-vector search uses [sparse vectors](https://www.pinecone.io/learn/sparse-retrieval/), which have a very large number of dimensions, where only a small proportion of values are non-zero. The dimensions represent words from a dictionary, and the values represent the importance of these words in the document. Words are scored independently and then summed, with the most similar documents scored highest.

For a legacy vector index, see [Query vectors](/guides/legacy/vectors-api/query-vectors#query-with-sparse-vectors). For a legacy integrated index, see [Search with text](/guides/legacy/records-api/search-with-text#search-with-sparse-embedding).

## Search a document index

In a [document index](/guides/indexes/data-modeling#documents), you choose how to score each search with a clause in `score_by`. Use a `sparse_embed` clause to search with text, or a `sparse_vector` clause to search with a sparse vector you generate yourself.

### Search with text

To search with text, the `string` field must declare `sparse_embed`, which enables [integrated embedding](/guides/search/integrated-embedding). Pinecone converts your query text to a sparse vector with the field's model. For example, this searches the `chunk_text` field of an index whose schema declares `"chunk_text": {"type": "string", "sparse_embed": {}}` and returns the 3 documents that best match "What is AAPL's outlook, considering both product launches and market conditions?":

```python Python theme={null}
from pinecone import Pinecone

pc = Pinecone(api_key="YOUR_API_KEY")

# To get the unique host for an index,
# see https://docs.pinecone.io/guides/indexes/target-an-index
index = pc.index(host="INDEX_HOST")

results = index.documents.search(
    namespace="example-namespace",
    top_k=3,
    score_by=[
        {
            "type": "sparse_embed",
            "fields": ["chunk_text"],
            "query": "What is AAPL's outlook, considering both product launches and market conditions?",
        }
    ],
    include_fields=["chunk_text", "quarter"],
)
```

```go Go theme={null}
package main

import (
    "context"

    "log"

    bytes, _ := json.MarshalIndent(obj, "", "  ")
    return string(bytes)

func main() {
    ctx := context.Background()

    pc, err := pinecone.NewClient(pinecone.NewClientParams{
        ApiKey: "YOUR_API_KEY",
    })
    if err != nil {
        log.Fatalf("Failed to create Client: %v", err)
    }

    // To get the unique host for an index,
    // see https://docs.pinecone.io/guides/indexes/target-an-index
    idxConnection, err := pc.Index(pinecone.NewIndexConnParams{Host: "INDEX_HOST", Namespace: "example-namespace"})
    if err != nil {
        log.Fatalf("Failed to create IndexConnection for Host: %v", err)
    }

    query := "What is AAPL's outlook, considering both product launches and market conditions?"
    res, err := idxConnection.SearchDocuments(ctx, &pinecone.SearchDocumentsRequest{
        TopK: 3,
        ScoreBy: []pinecone.DocumentScoringMethod{
            {Type: pinecone.DocumentScoringTypeSparseEmbed, Fields: []string{"chunk_text"}, Query: &query},
        },
        IncludeFields: []string{"chunk_text", "quarter"},
    })
    if err != nil {
        log.Fatalf("Failed to search documents: %v", err)
    }
    fmt.Println(prettifyStruct(res))
}
```

To require specific terms in each result, add a `$match_all` [text-match filter](/guides/search/filter-by-metadata#text-match-filters) on the same field, for example, `"filter": {"chunk_text": {"$match_all": "AAPL Q4"}}`. This works because Pinecone stores the field's text and indexes it for full-text search unless the field sets `store_text: false`.

### Search with a sparse vector

To search a `sparse_vector` field, pass a `sparse_vector` clause in `score_by` with the query's sparse vector, produced by the same encoder you used at upsert. For example, this searches the `sparse_embedding` field of the [`articles-hybrid` schema](/guides/search/full-text-search#example-schemas):

```python Python theme={null}
from pinecone import Pinecone

pc = Pinecone(api_key="YOUR_API_KEY")

# To get the unique host for an index,
# see https://docs.pinecone.io/guides/indexes/target-an-index
index = pc.index(host="INDEX_HOST")

results = index.documents.search(
    namespace="articles",
    top_k=3,
    score_by=[
        {
            "type": "sparse_vector",
            "fields": ["sparse_embedding"],
            "sparse_values": {"indices": [10, 45, 16], "values": [0.5, 0.5, 0.2]},
        }
    ],
    include_fields=["title"],
)
```
