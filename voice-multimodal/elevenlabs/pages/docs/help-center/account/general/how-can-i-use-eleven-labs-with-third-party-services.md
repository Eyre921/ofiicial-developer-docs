# How can I use ElevenLabs with third-party services?

Some third-party services offer API integration, allowing you to use your ElevenLabs account with their services.

To link your ElevenLabs account with an external service, you will need to use your API key. You can access your API keys from the [Developers page](https://elevenlabs.io/app/developers), under the API Keys tab. Do not show your API keys to anyone else. If someone gains access to one of your API keys, they can use your account as if they knew your password.

For more details, please see our article, [How to authorize yourself using your xi-api-key?](/docs/help-center/technical/how-do-i-authorize-myself-using-an-api-key)

If you are having trouble with a third-party service, we recommend contacting their support for assistance.
