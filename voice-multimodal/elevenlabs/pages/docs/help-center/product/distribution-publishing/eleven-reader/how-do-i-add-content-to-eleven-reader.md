# How do I add content to ElevenReader?

ElevenReader allows you to add content in four ways:

<img src="https://help.elevenlabs.io/hc/article_attachments/34275297067537" alt="" />

1. You can select <strong>Write text</strong> to enter text directly, either by typing or pasting text.

2. You can select <strong>Scan text</strong> to activate your camera and scan the text you want to read.

3. You can select <strong>Paste a link</strong> to input a URL, and the app will convert the contents of the web page.

4. You can select <strong>Upload a file</strong> to import a file. The following file types are supported:
