# Which formats can be used as the input audio for Voice Changer?

The following file formats can be used as the input audio for Voice Changer.

Audio:

* MP3
* M4A
* FLAC
* OGA
* OGG
* WAV

Video:

* MKV
* WEBM
* MP4
* MOV
