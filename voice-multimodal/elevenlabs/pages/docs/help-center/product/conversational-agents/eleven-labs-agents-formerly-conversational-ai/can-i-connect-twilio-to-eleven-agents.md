# Can I connect Twilio to ElevenAgents?

Yes — we offer full integration with Twilio for ElevenAgents.

Twilio makes it easy to handle both inbound and outbound calls through ElevenAgents. All you need is a paid Twilio account and an active Twilio phone number.

To get started:

Import your Twilio number into the platform.

Verify the number using your Twilio SID and Auth Token, available in the Twilio admin console.

Once verified, you can assign the number to a specific agent to handle incoming or outgoing
calls.

This setup allows your agent to seamlessly manage calls using your existing Twilio infrastructure.

For more information, please see our [ElevenAgents documentation.](/docs/agents-platform/phone-numbers/twilio-integration/native-integration)
