# How to read Word documents aloud

You can use ElevenReader to listen to Microsoft Word documents using AI voices. Upload a DOCX file, choose a voice, and listen to the document aloud.

ElevenReader supports Word documents that contain written text, including reports, essays, study materials, and other documents saved as DOCX files.

### How do I listen to a Word document with ElevenReader?

1. Open ElevenReader. Launch the app on your iPhone or Android device, or visit [elevenreader.io](https://elevenreader.io/) to use the web version.
2. Select **Upload a file**.
3. Find your Word document and select the DOCX file you want to listen to.
4. Wait for the file to be added to your library.
5. Open the imported document and press play.

You can also choose an AI voice and adjust the playback speed.

### What Word document formats does ElevenReader support?

ElevenReader supports Microsoft Word documents saved as DOCX (`.docx`).

Older Word documents saved as DOC (`.doc`) are not a supported upload format.

If your document is a DOC file, convert it to DOCX in Microsoft Word:

1. Open the document in Microsoft Word.
2. Select **File**, then **Save As** or **Save a Copy**, depending on your version of Word.
3. Choose **Word Document (.docx)** as the file format.
4. Save the document.
5. Upload the new DOCX file to ElevenReader.

You can also export the Word document as a PDF and upload that file instead.

### Can ElevenReader read tables, images, and other formatting in Word documents?

ElevenReader converts written text into speech. Some parts of a Word document do not translate directly into audio:

* **Tables.** Information in rows and columns may not keep its original structure when read aloud.
* **Images and charts.** Visual elements need to be viewed in the original document.
* **Text boxes and complex layouts.** Content in multiple columns or unusual layouts may not follow the expected reading order.
* **Special characters and symbols.** Some characters, abbreviations, and mathematical notation may not be pronounced as intended.

For documents containing complex formatting, we recommend keeping the original file available while listening.

### What if my Word document won't upload?

1. Check the file format. Confirm that the document is a DOCX file, not the older DOC format.
2. Check that the document opens. Open it in Microsoft Word or another compatible application to confirm that the file is not damaged.
3. Check your internet connection. Make sure your device is connected to Wi-Fi or mobile data.
4. Try uploading the document again. Close and reopen ElevenReader, then select **Upload a file**.
5. Check for app updates. Make sure you are using the latest version of ElevenReader.

If the document is password-protected, remove the password using an authorized method before you upload it.

You can also save the document as a new DOCX file, or export it as a PDF, and import it again.

### Can I listen to other document formats with ElevenReader?

Yes. In addition to Word documents, ElevenReader supports:

* PDF (`.pdf`)
* EPUB (`.epub`)
* Plain text (`.txt`)
* HTML (`.html`)

You can also type or paste text, scan printed pages, or import content from supported webpages.

For more information, see [How do I add content to ElevenReader?](/docs/help-center/product/mobile-apps/elevenreader/how-to-guides-for-elevenreader/how-do-i-add-content-to-elevenreader).
