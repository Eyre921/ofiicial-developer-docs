# How to read Google Docs aloud

You can use ElevenReader to listen to Google Docs using AI voices. **Open a webpage** lets you open a Google Doc and listen to it directly, without downloading or converting the file.

### How do I listen to Google Docs with ElevenReader?

1. Open ElevenReader on your iPhone or Android device.
2. Tap **+** and select **Open a webpage**.
3. Open Google Docs in ElevenReader's built-in browser.
4. Sign in to the Google account that contains the document, if you are prompted.
5. Open the Google Doc you want to hear.
6. Press play. ElevenReader reads the document aloud using an AI voice.

You can choose from more than 1,000 voices and adjust the playback speed.

### Do I need to download my Google Doc first?

No. You can listen through **Open a webpage** without downloading the document.

The Google Doc stays in Google Drive. It is not imported, copied, or saved to your ElevenReader library.

If you want the document as a separate file in your library, download it from Google Docs as a PDF or DOCX file and import it into ElevenReader.

### Can I listen to shared Google Docs?

You can listen to Google Docs that you already have permission to access.

If someone has shared a document with you, sign in to the Google account that has access and open the document in ElevenReader's built-in browser.

You need access to the document in Google Docs before you can listen to it.

### Can ElevenReader read tables, images, and other formatting in Google Docs?

ElevenReader reads text from supported webpages, including Google Docs. Some content does not translate clearly into spoken audio:

* **Tables.** Information in rows and columns can be difficult to follow when read aloud.
* **Images and charts.** Visual content needs to be viewed in the original document.
* **Mathematical equations.** Complex formulas and symbols may not be pronounced as intended.
* **Special characters.** Unusual spacing, abbreviations, and symbols can cause mispronunciations.

If your Google Doc contains complex formatting, you may find it helpful to keep the original document open while listening.

### Can I save Google Docs to my ElevenReader library?

Documents opened with **Open a webpage** are not saved to your ElevenReader library.

ElevenReader reads the content directly from Google Docs. The original document stays where it is.

To listen again, return to Google Docs in ElevenReader and open the document.

To keep a separate copy in your library, export the document as a PDF or DOCX file and upload it with **Upload a file**.

### What if ElevenReader can't read my Google Doc?

1. Check your access. Confirm that you are signed in to a Google account that can view the document.
2. Open the document again. Return to Google Docs through **Open a webpage** and select it.
3. Check your internet connection. Make sure your device is connected to Wi-Fi or mobile data.
4. Try another document. Open a different Google Doc to see whether the issue affects one file or several.
5. Use a supported file format. If the webpage method is not working, export the document as a PDF or DOCX file and upload it to ElevenReader.

If a word or phrase is consistently mispronounced, [contact Support](/docs/help-center/other/how-can-i-contact-support) and include the details.

For more information, see [How does “Open a webpage” work?](/docs/help-center/product/mobile-apps/elevenreader/how-to-guides-for-elevenreader/how-does-open-a-webpage-work).
