# Why can't I access my voices via third-party services?

If you've linked your ElevenLabs account with a third-party service but can't access the voices saved to [My Voices](https://elevenlabs.io/app/voice-lab), the issue is often related to your API key permissions.

By default, API keys are restricted. Make sure the key you're using has the permissions required by the service. For example, accessing and using your voices typically requires **Voices (read)** and **Text to Speech**.

You can review and update your API keys from the [Developers page](https://elevenlabs.io/app/developers), under the **API Keys** tab.

For more details, see [How to authorize yourself using your xi-api-key?](/docs/help-center/technical/how-do-i-authorize-myself-using-an-api-key).
