# How do I access ElevenLabs Default voices?

Our Default voices are being replaced with new voices that you will be able to use forever. All our Default voices will expire on December 31, 2026, and they will no longer be accessible after this date. As part of this process, Default voices are only available for accounts that were created before March 2026. 

If your account has access to Default voices, they will be available to select from the voice selection menu. They do not need to be added to My Voices. You can use the Type: <strong>Default</strong> filter in [My Voices](https://elevenlabs.io/app/voice-lab) to view all Default Voices.

Default voices will appear at the end of the voice selection menu. You can also search for a specific voice by typing the name in the search box.

If you are using the API, you can find the voice ID for Default voices in [My Voices](https://elevenlabs.io/app/voice-lab). Find the voice you want to use, then click the <strong>More actions</strong> (three dots) button and select <strong>Copy voice ID</strong> to copy the Voice ID to your clipboard.

You can also get the voice ID for Default voices by sending a GET request to the List voices endpoint. Please see the [API Reference](/docs/api-reference/voices/search) for full details.
