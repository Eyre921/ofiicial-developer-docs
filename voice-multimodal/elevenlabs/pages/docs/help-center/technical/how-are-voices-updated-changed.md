# How are voices updated & changed?

Some voices that were previously offered as Default voices have changed. We’ve worked to make this transition as seamless as possible by automatically routing them to new, similar voices. Your existing code will continue to function without any updates, but the resulting audio may sound different.

| Legacy voice | New voice | Gender | Accent   |
| ------------ | --------- | ------ | -------- |
| Ryan         | Arnold    | male   | American |

Legacy voices have now been deprecated. For more information, see [What are Legacy voices?](/docs/help-center/product/voice-customization/my-voices/what-are-legacy-voices)

If you use the API, previous Legacy voice IDs will automatically route to their replacement Default voice IDs.
