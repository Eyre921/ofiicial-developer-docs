# How much does it cost to use the API?

Most of our API endpoints are available for all plans, including the free plan. If you send a request to one of our API endpoints using your API key, it will deduct credits from your account. 

For full details of costs for all features, see our [API pricing. ](https://elevenlabs.io/pricing/api)
