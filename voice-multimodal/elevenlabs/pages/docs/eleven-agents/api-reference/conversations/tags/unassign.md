# Remove tag from conversation

DELETE https://api.elevenlabs.io/v1/convai/conversations/{conversation_id}/tags/{tag_id}

Remove a single conversation tag from a conversation.

Reference: https://elevenlabs.io/docs/eleven-agents/api-reference/conversations/tags/unassign
