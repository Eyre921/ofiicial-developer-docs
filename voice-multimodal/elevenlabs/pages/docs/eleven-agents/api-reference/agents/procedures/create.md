# Create Procedure

POST https://api.elevenlabs.io/v1/convai/agents/{agent_id}/branches/{branch_id}/procedures
Content-Type: application/json

Create a new procedure for the agent on a branch.

Reference: https://elevenlabs.io/docs/eleven-agents/api-reference/agents/procedures/create
