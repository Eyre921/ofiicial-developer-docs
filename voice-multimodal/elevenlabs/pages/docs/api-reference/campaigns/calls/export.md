# Export calls

GET https://api.elevenlabs.io/v1/convai/outbound-campaigns/campaigns/{campaign_id}/export

Download every call of a campaign, with its lead and conversation results, as CSV.

Reference: https://elevenlabs.io/docs/api-reference/campaigns/calls/export

## Servers

- `https://api.elevenlabs.io` (Production, default)
- `https://api.us.elevenlabs.io` (Production US)
- `https://api.eu.residency.elevenlabs.io` (Production EU)
- `https://api.in.residency.elevenlabs.io` (Production India)
- `https://api.sg.residency.elevenlabs.io` (Production Singapore)

## Request

### Path parameters

- `campaign_id` (string, required)

### Query parameters

- `limit` (integer, optional, nullable) — Only export the first N calls; used to preview the columns. Omit to export every call.

## Response

### 200

Campaign calls CSV.

- File download.

## Errors

### 422 Unprocessable Entity Error

Validation Error

- `detail` (list of ValidationError, optional)

## Types

### ValidationError

- `loc` (list of ValidationErrorLocItems, required)
- `msg` (string, required)
- `type` (string, required)

### ValidationErrorLocItems

- string
- integer
